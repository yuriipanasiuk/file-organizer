# File Organizer CLI

Інструмент командного рядка на Node.js для аналізу, організації та очищення директорій.

## Встановлення
1. Переконайтеся, що встановлено Node.js (версія 18+).
2. Клонуйте репозиторій.
3. Запустіть команди через npm або node.

## Команди

### 1. Scan (Сканування)
Збирає детальну статистику про файли (кількість, розміри, типи, вік, найбільші та найстаріші файли).
\`\`\`bash
npm run scan -- /шлях/до/директорії
# або
node file-organizer.js scan /шлях/до/директорії
\`\`\`

### 2. Duplicates (Пошук дублікатів)
Знаходить файли з однаковим вмістом (за SHA-256) та підраховує витрачене місце.
\`\`\`bash
npm run duplicates -- /шлях/до/директорії
\`\`\`

### 3. Organize (Сортування)
Копіює файли у нову директорію, розбиваючи їх по категоріях (Documents, Images, Code тощо). Використовує streams для великих файлів (≥10 MB).
\`\`\`bash
npm run organize -- /шлях/до/директорії --output /цільова/директорія
\`\`\`

### 4. Cleanup (Очищення)
Шукає старі файли. За замовчуванням працює в режимі `dry-run`. Для фактичного видалення додайте прапорець `--confirm`.
\`\`\`bash
npm run cleanup -- /шлях/до/директорії --older-than 90
npm run cleanup -- /шлях/до/директорії --older-than 90 --confirm
\`\`\`
